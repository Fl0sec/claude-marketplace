# claude-marketplace

NtTilt Claude Code marketplace.

Installation:

```bash
claude plugin marketplace add NtTilt/claude-marketplace
```

Update marketplace:

```bash
claude plugin marketplace update nttilt
```

## [ida-pro-mcp](https://github.com/NtTilt/ida-pro-mcp)

AI-powered reverse engineering assistant that bridges IDA Pro with language models through MCP.

```bash
claude plugin install ida-pro-mcp@nttilt
```
