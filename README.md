# claude-marketplace

fl0sec Claude Code marketplace.

Installation:

```bash
claude plugin marketplace add Fl0sec/claude-marketplace
```

Update marketplace:

```bash
claude plugin marketplace update fl0sec
```

## [ida-pro-mcp](https://github.com/Fl0sec/ida-pro-mcp)

AI-powered reverse engineering assistant that bridges IDA Pro with language models through MCP.

```bash
claude plugin install ida-pro-mcp@fl0sec
```
